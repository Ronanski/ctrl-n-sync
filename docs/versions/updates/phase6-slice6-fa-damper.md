# Phase 6 slice 6: full open / full close ng inlet damper ng FA blower A / B (2026-11-26 PHT)

Ano ang nakikita ng operator: ang ZSO / ZSC-FA1055-A1 at B1 (limit switch na "full open" / "full close" ng inlet flow control damper ng
FA blower, ang blower ng fluidizing air) ay may value na. Full open kapag ang posisyon ZT-FA1055-x1 ay 100 %, full close kapag 0 %; sa
pagitan ay parehong 0. Ang posisyon ay sumusunod sa MV ng FICFA1055A / B (ABC-014).

- Source: IO list STN101 I.0040 / I.0041 / I.008A / I.008B; ZT-FA1055-A1 / B1 STN101 AI0176 / AI0196 (unit.js ztMap); parehong end-of-travel rule.
- Walang logic sheet na bumabasa nito (CRT lang).
- Bilang: hindi nakakabit na I/O 115 -> 111; may value 2171 -> 2175; B2 53 -> 49.
- Hindi sinubok: sa browser (live app).
